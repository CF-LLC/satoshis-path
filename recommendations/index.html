Tools beginners commonly use

What each one is for, and the one thing to check before you sign up.

Buying small amounts

Strike ↗

App for buying Bitcoin and using Lightning.

Check first: Compare the quoted price and fees with another app for the same dollar amount.

River ↗

Bitcoin-only brokerage with recurring buys.

Check first: Read the current fee schedule for your purchase size.

Kraken ↗

Large exchange with a simple and a pro trading view.

Check first: The pro view usually shows lower trading fees than instant buy.

Self-custody wallets

Trezor ↗

Hardware wallet that keeps keys offline.

Check first: Buy only from the official store; never use a pre-set recovery phrase.

Ledger ↗

Hardware wallet that keeps keys offline.

Check first: Buy only from the official store; set the phrase up yourself.

Records and taxes

Koinly ↗

Imports exchange history to help prepare crypto tax reports.

Check first: Confirm it supports your country and exchanges before paying.

CoinTracker ↗

Portfolio and tax-report tool.

Check first: Free tiers are limited; check transaction limits.

Free learning and data

mempool.space ↗

See current network fees and confirm transactions.

Check first: Free; no account needed.

Bitcoin.org ↗

Long-standing introductory resource.

Check first: Free; no account needed.
